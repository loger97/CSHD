# CSHD

CSHD, or Crystal Seeker HD, is a mod of [Crystal Seeker](https://scratch.mit.edu/projects/463553665/fullscreen/) that makes modding easier.

## Weird files
In this repository, you will find uncompiled code in the form of .sb3 files; in order to edit them, use [Turbowarp](https://desktop.turbowarp.org/.).
Save data will be in .sav files and as-of right now can only be read by CSHD.
Level data is in two places; the first is in the `seeker.sb3` file, spesificly under the "root/data" path, the second place you can find level data is in the SDK directory each "scene" is in it's own .lvl file named after it's scene ID (you can look them up here: [Scene lookup](https://docs.google.com/spreadsheets/d/1I_gTPkNN0jfXKT9C4KQCN_SKyVVCb3gw8spMwzNKmLM/edit?gid=0#gid=0))
